# EDA: продажи и Telegram-публикации

Ноутбук `EDA.ipynb` содержит разведочный анализ исторических данных проекта: продаж и публикаций Telegram-канала.

Цель EDA — описать доступные данные, посмотреть динамику продаж и контента и определить, какие маркетинговые данные отсутствуют для полноценной атрибуции.

## Данные

В анализе используются:

- исторические обезличенные продажи;
- история публикаций основного Telegram-канала.

По исторической базе:

- **795** строк продаж;
- **606** уникальных клиентов;
- **18** продуктов;
- суммарная выручка — около **5,9 млн ₽**;
- медианный чек — около **7,5 тыс. ₽**.

## Классификация Telegram-постов

В ноутбуке реализован **rule-based классификатор публикаций**.

По тексту поста формируются дополнительные признаки:

- `post_type` — тип публикации;
- `product` — упомянутый продукт;
- `discount` — наличие скидки / промокода;
- `campaign` — предполагаемая кампания;
- `channel` — канал;
- `creative` — поле предусмотрено структурой, но в текущей версии не заполняется.

Для `post_type` используются эвристики по ключевым словам и регулярным выражениям.

Основные категории:

| Категория | Смысл |
|---|---|
| `content` | обычный информационный контент |
| `sale` | пост, связанный с продажей / запуском / набором |
| `discount` | скидка, акция или промокод |
| `external_ad` | упоминание внешней компании в промо-контексте |

`external_ad` — это **эвристическая категория текста поста в собственном Telegram-канале**, а не подтверждение платного внешнего рекламного размещения.

## Что показал EDA

Исторические данные позволяют наблюдать:

- покупки, суммы и продукты;
- динамику спроса;
- публикации собственного Telegram-канала;
- типы публикаций, полученные классификатором.

Но в исторических данных нет полной связи:

**конкретное рекламное размещение → пользователь → касания → заявка → покупка**

Поэтому по ним нельзя достоверно восстановить исторический ROMI внешней рекламы.

EDA используется как отправная точка для measurement-системы: он показывает, какие данные уже есть и какие события необходимо начать собирать для новых рекламных запусков.

---

## Связь с synthetic experiment

Классификатор Telegram-постов **не используется напрямую** в synthetic experiment.

Разделение следующее:

- `EDA.ipynb` — анализ реальной исторической информации;
- synthetic experiment — проверка attribution engine на искусственных данных с известным ground truth;
- Telegram-бот — сбор недостающих реальных касаний для новых кампаний.

В эксперимент из истории могут использоваться характеристики спроса, но классы `content`, `sale`, `discount` и `external_ad` не являются ground truth рекламного эффекта.
